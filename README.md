# Ionic Angular User Login App

This project is an Ionic Angular application featuring a basic user login system and a home page. It provides a simple interface for user authentication and navigation.

## Features

- **User Login**: Users can log in with their credentials.
- **Home Page**: After logging in, users are redirected to a home page displaying a welcome message.

## Project Structure

- **src**: Contains all the source files for the application.

## Setup

1. **Clone the Repository:**
   - Open your terminal and run:
     ```bash
     git clone https://github.com/Joe1Jun/IonicAngularFirstApp.git
     ```

2. **Navigate to the Project Directory:**
   - Change to the project directory:
     ```bash
     cd IonicAngularFirstApp
     ```

3. **Install Dependencies:**
   - Run the following command to install the required dependencies:
     ```bash
     npm install
     ```

4. **Run the Application:**
   - Start the Ionic development server:
     ```bash
     ionic serve
     ```

5. **Access the Application:**
   - Open your browser and go to `http://localhost:8100` to access the application.

## Usage

- Enter your credentials on the login page to log in.
- Upon successful login, you will be redirected to the home page.

## Dependencies

- **Ionic**: For building cross-platform mobile applications.
- **Angular**: The framework used for building the application.
